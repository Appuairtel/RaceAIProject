# RaceAIProject
# Smart Race Strategy AI Assistant

## Problem
Racing teams and fans often struggle to understand race strategy and pit stop decisions.

## Solution
This project uses AI to analyse race data and provide intelligent recommendations for race planning.

## Technologies Used
- IBM Granite
- Python
- Streamlit
- Pandas

## Features
- Upload race data
- Analyse tyre conditions
- Suggest pit stop decisions
- Generate AI race recommendations

## Future Improvements
- Live weather updates
- Real-time race data
- Advanced AI predictions
